# HUB – AI‑Core · iki1uc

## Zweck
HUB ist die zentrale KI‑Schaltstelle des iki1uc‑Systems.  
Es verbindet NC, PQ, TMP, NET und steuert TEAM, HH, RTH, POOK und KOOP.

HUB ist die Stabilisationsachse (ANKER‑S01) und dient als:

- AI‑Core
- Runtime‑Modulator
- Fusion‑Zentrale
- System‑Synchronisator
- Puls‑Engine
